# K3

## Modul K3 & Keamanan — reuse fondasi Operasi/HAR
Modul K3 SEJAJAR Operasi/HAR — pakai ulang, jangan duplikasi. RBAC: PermissionName `k3.*` (input/laporan/monitoring/master, grup PermissionGroup::K3), role baru RoleName::TeamLeaderK3 penuh + Manager UL view (k3.laporan/monitoring). work_modules seed `k3`. Master via engine bersama (MasterRegistry + MasterFields + ManagesMasterResources + MasterScreen): global (k3_activity_types, apd_categories, equipment_categories) tanpa unit_id; per-unit (patrol_locations, security_posts, emergency_equipments, apd_items, fire_extinguishers, p3k_boxes, inspection_checklists) pakai trait BelongsToUnit. Field `relation` engine sudah digeneralisasi (source table + label column + flag unitScoped) — relasi global spt apd_items→apd_categories pakai unitScoped:false. Form checklist seragam WAJIB pola generik inspections+inspection_results (bukan tabel per-form). No. Dokumen ISO (SMT-FM-AK3-*) editable, bukan auto-generate. Kadaluarsa = badge monitoring (≤60 hari), bukan push. Foto/lampiran ke storage (path), bukan blob.

## Satu sumber tabel untuk input K3: K3InputTables
Setiap halaman k3/input punya tabel di `App\Services\K3\K3InputTables` (key = K3InputTables::INPUTS), dipakai bersama oleh PDF (A4 landscape, `resources/views/k3/input/{key}-pdf.blade.php`, route `k3.input.export.pdf`; air-limbah redirect ke PDF resminya), Excel (JSON `k3.input.export.data` → ExcelJS `lib/k3-input-excel.ts`) dan Laporan K3 (`$data['inputs']`). Baris = persis yang tampil di halaman input: data tersimpan, atau bila belum ada, master/default halaman (DEFAULTS public di controller-nya). `has_data` = ada baris; `saved` = benar-benar tersimpan. Poin laporan tanpa input sendiri diisi dari baris jadwal (K3ReportBuilder::formulirPoints, pencarian kata kunci) dengan catatan sumber; garis merah hanya bila tidak ada sumber sama sekali.
